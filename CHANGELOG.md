# Changelog

All notable changes to Licra are documented here.

## [v1.0.0] - 2026-08-14

### Added
- Static single-file PWA build (`build-pwa.py`) — offline-first web UI with no server required
- `static/index.html` generated from embedded HTML/CSS/JS sources
- Service worker with blob URL, localStorage state persistence
- `build-pwa.ps1` removed in favor of Python build script

## [v0.1.0] - 2026-08-14

### Added
- Initial release: Rust-based granular license compiler with a 300+ question questionnaire, 30+ SPDX license types, 9 export formats, digital signatures, QR verification codes, and an interactive web UI
- Project documentation

### Fixed
- gitattributes normalization rules
